# Wedding_invitation
Invitation webiste

## Интерактивная рассадка

Список гостей **не хранится в этом репозитории**. Статический сайт получает только до пяти подсказок по введённому фрагменту и место выбранного гостя из отдельного Google Apps Script Web App. Перед публикацией нужно один раз настроить этот Web App.

### 1. Создайте закрытую таблицу

1. Создайте Google Sheet и назовите рабочий лист `Seating`.
2. В первой строке создайте колонки в таком порядке (порядок не важен, но имена важны): `guest_id`, `surname`, `first_name`, `display_name`, `search_key`, `table_id`, `seat_id`, `active`, `public_hint`.
3. На каждую строку добавьте одного гостя. В `guest_id` используйте стабильный случайный UUID, а не порядковый номер. Его удобно создать формулой `=LOWER(DEC2HEX(RANDBETWEEN(0,4294967295),8)&"-"&DEC2HEX(RANDBETWEEN(0,65535),4)&"-4"&RIGHT(DEC2HEX(RANDBETWEEN(0,65535),4),3)&"-"&DEC2HEX(RANDBETWEEN(32768,49151),4)&"-"&DEC2HEX(RANDBETWEEN(0,4294967295),8)&DEC2HEX(RANDBETWEEN(0,4294967295),4))`, затем вставьте значения вместо формул.
4. Пример строки: `UUID | Иванова | Анна | Анна Иванова | иванова анна | T2 | (пусто) | TRUE |`.
5. Оставляйте `seat_id` пустым, пока назначен только стол. Позже используйте глобальный ID из `seating/layout-config.js`, например `S-13`.
6. Откройте «Настройки доступа» таблицы и убедитесь, что «Общий доступ» — **Ограниченный**. Не публикуйте таблицу в интернете.

Не добавляйте в этот лист телефоны, e-mail, ответы RSVP или внутренние заметки: API специально не читает их в ответы, но лист рассадки лучше оставить минимальным.

### 2. Разверните Apps Script API

1. В таблице выберите «Расширения → Apps Script» или создайте отдельный проект на [script.google.com](https://script.google.com/).
2. Скопируйте содержимое `seating/apps-script.gs` в редактор, сохраните проект.
3. В Apps Script откройте «Project Settings → Script properties», добавьте свойство `SEATING_SPREADSHEET_ID`. Его значение — часть URL таблицы между `/d/` и `/edit`.
4. Нажмите «Deploy → New deployment → Web app». Установите: «Execute as: Me», «Who has access: Anyone». Подтвердите разрешение Script на доступ к вашей закрытой таблице.
5. Скопируйте URL, который оканчивается на `/exec` (не `/dev`). Откройте его в отдельной вкладке с `?action=searchGuests&q=анн`: должен прийти JSON только с `guestId`, `displayName` и `hint`.
6. В `index.html` найдите `<meta name="seating-api-url" content="">` и вставьте этот URL внутрь `content`. Это публичный URL, не секрет. Не вставляйте туда ID таблицы, ключи или токены.
7. Обновите развертывание после изменения серверного кода. Изменения данных в Sheet применяются максимум через пять минут из-за кэша; для срочного обновления измените `cacheSeconds` или очистите кэш в Apps Script.

RSVP использует свой прежний endpoint и не изменяется этой интеграцией. Рекомендуется держать рассадку в отдельном Apps Script deployment, чтобы изменения поиска никак не влияли на RSVP.

### Публичный просмотр карты

Карта поддерживает два дополнительных действия: просмотр гостей выбранного стола и имя гостя по нажатию на назначенное место. Скопируйте обновлённый `seating/apps-script.gs` в Apps Script и создайте **New version** deployment. Эти действия намеренно возвращают только `displayName`, `tableId` и `seatId` — без контактов, RSVP или заметок. Поскольку посетитель может нажимать столы и места, это делает имена и рассадку публичными для гостей сайта.

### 3. Изменение схемы зала

Геометрия находится в `seating/layout-config.js`. У каждого стола есть стабильный `id`, `x`, `y`, `width`, `height`; места имеют стабильные `id`, `x`, `y`. Меняйте координаты и размеры для новой схемы, но не меняйте ID столов/мест, если хотите сохранить существующие назначения в Sheet. После изменения выполните `npm run test:seating` и опубликуйте сайт. В текущей версии T1–T2 идут по горизонтали, а T3–T4 продолжают конструкцию вертикально вверх справа от T2. Всего 39 мест: `S-01`…`S-39` идут по часовой стрелке, начиная сверху T4. Два места молодожёнов в нижнем стыке T1/T2 — `S-17` и `S-18` — помечены сердцами и не должны получать `seat_id` в таблице.

### Проверка перед публикацией

- Откройте DevTools → Network: при загрузке страницы не должно быть запроса за полным списком гостей.
- Поиск стартует только после трёх символов и показывает не больше пяти вариантов.
- Проверьте гостя с пустым `seat_id`: должен подсветиться только стол.
- Проверьте гостя с `seat_id` из конфигурации: должен выделиться конкретный стул.
- Убедитесь, что RSVP всё ещё отправляет ответ.
